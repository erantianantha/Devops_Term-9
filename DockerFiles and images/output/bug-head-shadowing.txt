--- experiment A: change the SOURCE, rebuild ---


########## -14


rebuild after a source change: 2 seconds
npm install was CACHED: the manifest did not change, so the layer that
installs dependencies was reused. Only the copy and the bundle re-ran.

--- experiment B: change PACKAGE.JSON, rebuild ---


########## -14


rebuild after a manifest change: 8 seconds
npm install ran again in BOTH stages. Every instruction after the one
that changed is invalidated, whether or not it depends on the change.
