Only instructions that add files have a size. WORKDIR, ENV, EXPOSE,
USER and CMD are metadata: they are layers, but 0 bytes of them.

--- experiment A: change the SOURCE only, rebuild ---

  CACHED    [builder 3/8] COPY package.json ./
  CACHED    [builder 4/8] RUN npm install --no-audit --no-fund
  CACHED    [builder 5/8] COPY build.js ./
  re-ran    [builder 6/8] COPY src ./src
  re-ran    [builder 7/8] RUN npm run build
  re-ran    [builder 8/8] RUN test -s dist/bundle.js && wc -c dist/bundle.js
  CACHED    [runtime 3/5] COPY package.json ./
  CACHED    [runtime 4/5] RUN npm install --omit=dev --no-audit --no-fund && npm cache clean --force
  CACHED    [runtime 5/5] COPY --from=builder /build/dist/bundle.js ./bundle.js
  3 seconds

  npm install was reused in both stages. The manifest did not change,
  and it is copied BEFORE the source, so the install layer is untouched.

--- experiment B: change PACKAGE.JSON, rebuild ---

  re-ran    [builder 3/8] COPY package.json ./
  re-ran    [builder 4/8] RUN npm install --no-audit --no-fund
  re-ran    [builder 5/8] COPY build.js ./
  re-ran    [builder 6/8] COPY src ./src
  re-ran    [builder 7/8] RUN npm run build
  re-ran    [builder 8/8] RUN test -s dist/bundle.js && wc -c dist/bundle.js
  re-ran    [runtime 3/5] COPY package.json ./
  re-ran    [runtime 4/5] RUN npm install --omit=dev --no-audit --no-fund && npm cache clean --force
  re-ran    [runtime 5/5] COPY --from=builder /build/dist/bundle.js ./bundle.js
  8 seconds

  every instruction from the changed COPY downwards re-ran, in both
  stages, including two npm installs -- whether or not it had anything
  to do with the version number that changed.

  full logs: /tmp/build-a.log and /tmp/build-b.log
