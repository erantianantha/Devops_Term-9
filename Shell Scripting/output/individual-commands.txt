### mkdir, touch, and the two redirections

$ mkdir -p /tmp/redir-demo && touch /tmp/redir-demo/notes.txt && ls -l /tmp/redir-demo
total 0
-rw-r--r-- 1 anantha 197609 0 Sep  4 23:12 notes.txt

$ echo 'first line'  >  /tmp/redir-demo/notes.txt
$ echo 'second line' >> /tmp/redir-demo/notes.txt
$ cat /tmp/redir-demo/notes.txt
first line
second line

$ echo 'this REPLACES everything' > /tmp/redir-demo/notes.txt
$ cat /tmp/redir-demo/notes.txt
this REPLACES everything

  > truncates first, >> appends. One accidental > in a loop and the file
  contains only the last iteration.
